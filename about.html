About this template

Designed to help you teach HTML, semantic tags, and external CSS with a fun gaming theme.

Semantic tags

Every page uses <header>, <nav>, <main>, <section>, <article>, <figure> and <footer> where they make sense.

Non-semantic tags

We also use <div> for layout wrappers and <span> for small inline elements like badges and coloured labels.

tips

Here are some ideas for extending this template:

  • Change colours in :root to create a new theme.
  • Add a new game row to the table on games.html.
  • Add a new screenshot card to the gallery page.
  • Explain the difference between semantic and non-semantic tags.
